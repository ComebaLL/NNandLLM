## Воходные/ выходные данные LLM

вход
конексткое окно:
- информация об интсрументах
- системный промтн
- чат, пользовательские промты + ответы
- другие данные файлы
- память
- результаты работы инструментов

выход
- обычный текст
- специальные токены
- структурированный текст (json и др.)
- вызов инструментов

## цепочки рассуждений

- защита от дисциляции (обучение с учителем)
    провайдеры скрывают цепочку размышлений
- безопасность:
    - модель может сгенерировать небезопасный ответ
- защита контекст от гниения 

## Режим рассуждения

- Маршрутизация моделей при вкл/выкл режима рассуждения
- инъекция префикса ответа: орекстратор формирует запрос и принудительно подставляет в начало ответа ассистента пустой блок рассуждений
- маскирование токенов(отключать какие-то токены)
- специальный управляющий токен в промте


## Ограничение бюджета рассуждения

### Уровень общих возможностей языковой модели

- параметры модели:
    - знания, навыки, закономерности
- доступная задача в рамках задачи(что подано в контекст)
- увеличение времени ответа(режим рассуждения)


### jagged AI frontier 
модель решает сложные задачи, но проваливается на простых задачах

### Тех устройства LLM и сервера LLM

 движок инференса - отвчает за:
    - загрузка модели в видео/оперативную память
    - трансляция графов вычислений на gpu/cpu
    - управление kv-кешэм и выполняет прямой проход для расчета распределения вероятностей токенов

 файл модели
- веса - таблицы со значениями
- метаданные - описание архитектуры сети
- словарь токенизатора - набор токенов и id

оркестратор
- компонент, управляющий циклом взаимодействия ползователя, LLM, исполнителей интсрументов

инструмент - функциональный инструмент к пк программе, выполняемой вне LLM, модель генерирует текс с вызовами функций

граудинг - ответ полученый на основе вызовов инструментов

### цикл вызова инструментов(оркестрации)

1. оркестратор добавляет описание инструмента
2. модель решает, что нужен вызов и генерирует ео
3. оркестратор приостанавливает генерацию ответа и выполняет функцию
...



# Лекция 17.10 Агенты и агентское кодирование

- словарь токенезатора

инструменты нужны:
 - данные устарели
 - точные вычисления или исполнения лагоритмов
 - проверка формального доказательства


 Агент - все что может воспринимать среду с помощью сенсоров и взаимодействовать на эту среду с помощь актуаторов

 агент = LLM + harness(программная обвязка)/ LLM + tools + memory + planning

 уровни агентности:

 - чат-бот
 - агентный контйнер
 - самостоятельное формирование и исполнение плана
 - групповое планирование и исполнение
